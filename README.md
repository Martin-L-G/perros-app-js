# App de Perros 🐶

Una aplicación web desarrollada con JavaScript Vainilla para consultar fotos de perros según su raza.

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (ES6)
* Consumo de API REST (Dog API) mediante `fetch()`

## Instalación y uso
1. Clonar este repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web.
3. Ingresar el nombre de una raza en inglés (ej: `hound`, `boxer`, `pug`) y hacer clic en Buscar.
