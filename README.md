# App de Gatos 🐱

Una aplicación web desarrollada con JavaScript Vainilla para consultar fotos de gatos según su raza. 

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (ES6+ utilizando `async/await`)
* Consumo de API REST (The Cat API) 

## Instalación y uso
1. Clonar este repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web (recomendado usar la extensión Live Server).
3. Ingresar el código de 4 letras de una raza felina (ej: `siam` para Siamés, `beng` para Bengalí, `pers` para Persa) y hacer clic en Buscar.
